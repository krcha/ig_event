Uputstvo za instalaciju

U Safariju na iPhone-u

  1. Otvori deljenje

    Dodirni Share . Ako ga ne vidiš, otvori meni stranice pa izaberi Share.

    eventzeka.com
    ShareDodirni ovde
    Add to Bookmarks

  2. Dodaj na početni ekran

    U listi pronađi Add to Home Screen. Po potrebi pomeri listu nadole.

    Event Zekaeventzeka.com
    Find on Page
    Add to Home Screen

  3. Potvrdi dodavanje

    Ako se prikazuje Open as Web App, ostavi uključeno. Zatim dodirni Add.

    CancelAdd to Home ScreenAdd
    Event Zekaeventzeka.com
    Open as Web App

Ilustracije menija. Nazivi i raspored zavise od verzije i jezika iOS-a.

U Chrome-u na Android telefonu

  1. Otvori Chrome meni

    Na sajtu eventzeka.com dodirni tri tačke u Chrome-u.

    eventzeka.com

  2. Pronađi instaliranje

    Izaberi Install and create shortcut. U nekim verzijama piše Install app ili Add to Home screen.

    Find in page
    Install and create shortcut

  3. Potvrdi instaliranje

    Dodirni Install i prati potvrdu telefona. Ako nudi samo prečicu, potvrdi dodavanje prečice.

    Event Zekaeventzeka.com
    CancelInstall

Ilustracije menija. Dostupna opcija zavisi od Chrome-a i uređaja.

Chrome na računaru

  1. Otvori eventzeka.com

    U Chrome-u otvori meni sa tri tačke.

  2. Pronađi instaliranje

    Izaberi Cast, save, and share, pa Install page as app…. Može biti dostupna i ikonica za instaliranje u adresnoj traci.

    Cast, save, and share
    Install page as app…

  3. Potvrdi sa Install

    Event Zeku zatim otvaraš iz liste svojih aplikacija.

Koristim Safari na Mac-u

Na macOS Sonoma 14 ili novijem: Share → Add to Dock → Add. Naziv i adresu proveri pre potvrde.

EventZeka App je web aplikacija koja se dodaje iz pregledača. Za pregled događaja potreban je internet.
